Diagrammes de Séquence (UML)

Voici l'équivalent parfait de vos logigrammes (votre image) transformés en Diagrammes de Séquence UML !
Faites votre capture (Windows + Maj + S) pour l'ajouter à votre projet.

1. Séquence : Inscription au Tournoi

sequenceDiagram autonumber actor Participant participant Plateforme as Plateforme (Système) participant DB as Base de Données Participant->>Plateforme: Accède à la plateforme Participant->>Plateforme: S'inscrit / Se connecte Participant->>Plateforme: Remplit le formulaire d'inscription Plateforme->>Plateforme: Vérifie les informations (Valides ?) alt Informations Non Valides Plateforme-->>Participant: Affiche les erreurs (Demande de corriger) else Informations Valides Participant->>Plateforme: Crée une équipe / Rejoindre une équipe Participant->>Plateforme: Effectue le paiement Plateforme->>Plateforme: Vérifie le statut du paiement alt Paiement Refusé Plateforme-->>Participant: Demande une autre méthode / Réessayer else Paiement Accepté Plateforme->>DB: Sauvegarde l'inscription et le paiement DB-->>Plateforme: Confirmation d'enregistrement Plateforme-->>Participant: Confirme l'inscription au tournoi (Fin) end end

2. Séquence : Gestion des Équipes

sequenceDiagram autonumber actor Utilisateur participant Plateforme as Plateforme (Système) participant DB as Base de Données Utilisateur->>Plateforme: Se connecte à l'application alt L'utilisateur choisit la Création d'équipe Utilisateur->>Plateforme: Crée l'équipe (nom + joueurs) Plateforme->>DB: Enregistre la nouvelle équipe en base DB-->>Plateforme: Confirmation de l'équipe créée Plateforme-->>Utilisateur: Confirme la création de l'équipe (Équipe confirmée) else L'utilisateur choisit de Rejoindre (Code) Utilisateur->>Plateforme: Entre le code de l'équipe existante Plateforme->>DB: Vérifie si le code est correct DB-->>Plateforme: Retourne le résultat (Valide ou Invalide) alt Code Invalide Plateforme-->>Utilisateur: Affiche erreur (code invalide, réessayer) else Code Valide Plateforme->>DB: Ajoute l'utilisateur à l'équipe DB-->>Plateforme: Confirmation Plateforme-->>Utilisateur: Rejoint l'équipe avec succès (Équipe confirmée) end end
