Contexte du projet :
- Application web ASP.NET Core MVC
- Couche presentation : Views Razor, fichiers statiques wwwroot, Session HTTP

- Couche metier : PasswordHasher / IPasswordHasher, regles de connexion, roles, inscription, paiement simule, gestion d’equipe
- Couche donnees : GolfDbContext avec les entites Utilisateur, Tournoi, Participant, Equipe, Commandite
- Base de donnees : SQL Server
- Stockage de fichiers : images de tournois dans wwwroot/images/tournois

- Participant
- Administrateur
- Commanditaire
